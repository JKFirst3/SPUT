# Mitwirken

1. Forke das Repository und erstelle einen Branch für deine Änderung.
2. Installiere mit `npm ci --ignore-scripts` und starte die App mit `npm start`.
3. Führe `npm test` aus. Mit `npm run demo` kannst du eine synthetische Excel-Datei für manuelle Importtests erstellen.
4. Öffne einen Pull Request mit einer kurzen Beschreibung und den geprüften Schritten.

Bitte verwende ausschließlich synthetische Studiendaten in Commits, Issues und Pull Requests. Melde Sicherheitsprobleme [privat](SECURITY.md).

Änderungen an Parser, Statistik oder Exporten sollten die vorhandenen Formate berücksichtigen. Die [Architekturübersicht](docs/ARCHITECTURE.md) beschreibt die Zuständigkeiten der Module.
